# Design system

Os valores vivem em [tokens.json](tokens.json); este arquivo explica como usá-los.

## Cores

| Token | Uso |
|---|---|
| `color.primary` | Ações principais |
| `color.background` | Fundo das telas |
| `color.text` | Texto padrão |

## Tipografia

| Token | Uso |
|---|---|
| `font.size.body` | Texto corrido |
| `font.size.title` | Títulos de tela |

## Espaçamento

Escala em múltiplos de `space.unit`.
