# Roadmap

Status: `todo` · `doing` · `done`. O roadmap guarda o destino de cada linha: `doing` quando a
task começa (`/implementar`) e `done` já no PR dela (`/abrir-pr`), para entrar na `main` com o
merge. O andamento real (PR aberto, issue fechada) o board mostra, pelo `./scripts/sync-board.sh`.

A ordem das linhas é a ordem de execução: a primeira linha `todo` é sempre a próxima.
Cada linha é uma issue. Linhas são criadas por `./scripts/new-issue.sh` e o status muda por
`./scripts/task-status.sh`; a coluna Ordem é renumerada pelos scripts e a coluna PR é
preenchida pelo `./scripts/open-pr.sh` ao abrir o PR.
